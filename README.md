# Granova Landing Page (React + Vite)

## Menjalankan
    npm install
    npm run dev      # buka http://localhost:5173
    npm run build    # hasil produksi di folder dist/

## Mengganti gambar
Timpa file di `public/images/` dengan nama yang sama:
logo-granova.png, tas-hero.png, koleksi-tas.png, p1.png ... p6.png
(gambar bawaan dipotong dari screenshot, jadi resolusinya rendah)

## Mengganti nomor WhatsApp
Ubah konstanta `WA` di `src/App.jsx`.
